# Design documents

구현 계획과 grilling 결과는 GitHub Issue 단위로 관리한다.

```text
issue-<number>-<slug>.md
```

Phase, milestone과 vertical slice는 독립 계획 문서가 아니라 해당 issue 문서의 section이다. 작성·갱신 workflow와 source-of-truth 경계는 [`docs/agents/design-workflow.md`](../agents/design-workflow.md)를 따른다.
